# Product

## Register

product

## Users

Ahmed uses this locally while working across Codex and OpenCode. He needs to choose the right Codex conversation, send a request, and immediately understand whether OpenCode received it, is working, needs clarification, or has replied.

## Product Purpose

Relay Room is a personal, Arabic-first control surface for one Codex-to-OpenCode workflow. Its job is to make the handoff observable without turning the workflow into a task board or hiding agent state behind technical logs.

## Brand Personality

Clear, calm, technically honest. The interface should explain what is happening in plain Arabic and show the actual message path without decoration or vague status language.

## Anti-references

Avoid generic SaaS metric dashboards, repeated cards, opaque "working" states, and task-management language. Do not imitate a terminal or a marketing landing page.

## Design Principles

1. Make the active conversation unmistakable.
2. Show the message handoff as evidence, not as a guessed status.
3. Keep Codex and OpenCode roles visually separate without separating the user's workflow.
4. Prefer clear next actions over technical detail.
5. Preserve Arabic reading flow while keeping IDs and code legible.

## Accessibility & Inclusion

Support keyboard navigation, visible focus states, semantic labels, high-contrast state cues, and reduced motion preferences. Arabic is the primary interface language; technical identifiers remain readable left-to-right.
